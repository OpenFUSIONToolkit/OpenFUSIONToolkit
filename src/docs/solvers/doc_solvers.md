Linear Solvers     {#doc_solvers}
==============

This section describes the linear solvers and preconditioners available through Open FUSION Toolkit (OFT) solver
objects and how to configure them. Additional methods may be used internally by a backend, but only those directly
supported by OFT are documented here.

 - \subpage doc_solvers_xml_ref : Defining solvers in the XML input file and the options for each method. Start
   here to change the solvers used by a physics module.
 - \subpage doc_solvers_api : Creating and applying solver objects in Fortran, plus eigenvalue and non-linear solvers.
 - \subpage doc_solvers_backends : Native and PETSc backends, valid combinations and PETSc specific behavior.
